# Showreel — Glossary

Each thing in the app has one name. Use these words in buttons, menus,
titles, tooltips, errors, and VoiceOver labels.

## Things

| Term | Means | Not |
| --- | --- | --- |
| Project | One recording and everything you did to it in the editor | video, file, session, clip (in the UI) |
| Library | The window that lists all projects | gallery, home, dashboard |
| Recording | The act of capturing, and the raw tracks it writes | capture, take, session |
| Source | What gets recorded: a display, a window, or an area | target, input, region |
| Display | A whole screen | monitor, screen (as a source) |
| Window | One app window, as a source | app |
| Area | A rectangle you drag out on a display | region, selection, custom |
| Microphone | Your voice input; short label "Mic" on toggles only | audio input, voice |
| Camera | Your face input | webcam, FaceTime camera |
| System Audio | Sounds your Mac plays | computer audio, desktop audio, internal audio |
| Camera Bubble | The floating view of your camera, during recording and in the video | webcam overlay, circle, PiP, face cam |
| Record Panel | The floating panel where you set up and start a recording | toolbar, launcher, HUD |
| Recording Controls | The small floating bar shown while recording: time, Pause, Stop, Restart | HUD, toolbar |
| Countdown | The 3, 2, 1 shown before recording starts | timer |
| Editor | The window where you style, zoom, cut, and export a project | studio, timeline view |
| Timeline | The tracks at the bottom of the editor | sequence |
| Clip | The video block on the timeline | segment |
| Zoom | A timed zoom-in on part of the screen | zoom segment, focus, magnify |
| Style | Background, padding, rounding, shadow, and frame together | theme, look, design |
| Preset | A saved style | template |
| Captions | Timed text from your voice | subtitles, transcript |
| Caption | One line of captions, shown for a few seconds | subtitle, line, segment |
| Blend | A background Showreel draws itself: soft glows of color over a base, sharp at any size | mesh gradient, aurora, glow background |
| Blur | A timed rectangle that hides part of the screen, blurred or pixelated | redact, mask, censor, blur region |
| Speech Model | The on-device model that turns your voice into captions: Apple, Whisper Small, or Whisper Large v3 Turbo | engine, ASR, transcriber |
| From Handy | A Whisper model Showreel reads from the Handy app's folder instead of downloading it | shared, imported |
| Export | Render the project to a video file | download, render, save as |
| Format | MP4, MOV, or GIF: the kind of file an export makes | file type, container, codec |
| Resolution | 720p, 1080p, or 4K: the video's short side in pixels | size, dimensions |
| Frame Rate | Frames each second, shown as "30 fps" | fps (alone), smoothness |
| Quality | Standard, High, or Best: more quality makes a bigger file | bitrate, compression |
| Record Shortcut | The keys that start and stop recording from any app (⌃⌥⌘R) | hotkey, global shortcut |
| Projects folder | Where recordings are kept (~/Movies/Showreel) | library folder, storage |
| Exports folder | Where the Export save panel opens | save location, output folder |
| Style for New Recordings | The preset every new project starts with | default preset, default style |
| Cursor style | How the cursor looks in the video: System, No Cursor, a style Showreel draws, or your own picture | cursor theme, skin, pointer |

## Actions

| Term | Means | Not |
| --- | --- | --- |
| Allow | Grant Showreel access to screen, mic, or camera | enable, authorize, permit |
| New Recording | Open the record panel | start, capture |
| Start Recording | Begin the countdown and record | go, rec |
| Pause / Resume | Hold and continue the recording with no gap | stop (for pause) |
| Stop | End the recording and open the project | finish, done, end |
| Restart | Throw away this recording (it goes to the Trash) and count down again | retake, redo, reset |
| Rename | Change a project's title | edit name |
| Show in Finder | Reveal the project folder | open folder, reveal |
| Duplicate | Copy a project with its edits | clone, copy |
| Move to Trash | Remove a project. It can be restored from the Trash or with Undo | delete, remove |
| Generate Captions | Make captions from the microphone recording, on this Mac | transcribe, auto caption |
| Add Blur | Put a blur on the playhead and draw it on the canvas | redact, add mask |
| Download | Get a speech model once, to use on this Mac | install, fetch |
| Mute Section | Silence the audio of the selected section; the video keeps playing | mute clip, silence |
| Reduce Noise | Remove fan hum and room noise from the mic, on this Mac | denoise, noise gate, voice isolation |
